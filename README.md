# Don't Open the Door

A short interactive psychological horror game built as my first GitHub Pages project.

You wake up on the floor of an unfamiliar room at 03:17.

Someone is knocking.

A phone, a mirror and a closed door are the only clues you have.

The obvious choice may not be the right one.

**[Play Don't Open the Door](https://kawaii-neko07.github.io/dont-open-the-door/)**

The game is currently available in Polish.

## About the game

*Don't Open the Door* is a small branching narrative experiment focused on atmosphere, uncertainty and the consequences of player choices.

The player explores a single mysterious situation through short text scenes and decisions. Some information changes the options available later in the story, so exploring the environment matters.

The game contains:

- branching narrative paths
- 4 different endings
- 1 hidden ending
- conditional choices
- persistent ending discovery
- replayable paths
- subtle interface animations

## How it works

The game tracks several actions during each playthrough.

For example, it remembers whether the player:

- read the message
- investigated the mirror
- heard the mysterious voice

A particular combination of discoveries unlocks an option that otherwise remains hidden.

Discovered endings are saved locally in the browser, allowing the player to gradually reach **4/4 endings** across multiple playthroughs.
